## 📱 অ্যাপটির সংক্ষেপ (App Overview)

* **Chapter 2:** Machine Learning (Supervised vs Unsupervised)
* **Chapter 3:** Deep Learning & Neural Networks
* **Chapter 4:** Natural Language Processing (NLP)
* **Chapter 5:** Computer Vision & Perception

### ৩. অ্যাডাপ্টিভ মাস্টার কুইজ (Adaptive Assessment System)
পুরো কোর্স শেষে **১০টি বহুনির্বাচনী প্রশ্ন (MCQs)** রাখা হয়েছে।

> ⚠️ **বিশেষ নিয়ম (Adaptive Logic):** 
> কুইজ চলাকালীন কোনো প্রশ্নের উত্তর ভুল হলে, অ্যাপটি সরাসরি শিক্ষার্থীকে **ঐ নির্দিষ্ট টপিকের চ্যাপ্টারে রিভিউ করতে নিয়ে যাবে** এবং কুইজটি **পুনরায় ১ম প্রশ্ন থেকে শুরু হবে**—যাতে বিষয়টি শতভাগ আয়ত্তে আসে।

## 📝 কুইজের ১০টি প্রশ্নের সঠিক উত্তর (Quiz Answer Key)

| # | প্রশ্ন (Question) | সঠিক উত্তর (Correct Answer) |
|---|---|---|
| **১** | What is the key distinction of Artificial Narrow Intelligence (ANI)? | **It is designed and trained to perform a specific dedicated task.** |
| **২** | Which theoretical concept describes AI capable of performing ANY intellectual task a human can do? | **Artificial General Intelligence (AGI)** |
| **৩** | Supervised Learning algorithms require which of the following dataset types? | **Labeled training dataset** |
| **৪** | Which machine learning approach is primarily used for finding hidden customer segments in unlabeled data? | **Unsupervised Learning / Clustering** |
| **৫** | Deep Learning models are fundamentally inspired by which biological structure? | **Biological neural networks in the human brain** |
| **৬** | What advantage does Deep Learning offer over classical machine learning algorithms? | **It automatically extracts feature hierarchies from complex raw data.** |
| **৭** | Which branch of AI enables virtual voice assistants to understand human spoken commands? | **Natural Language Processing (NLP)** |
| **৮** | Self-driving cars rely primarily on which AI domain to perceive traffic signals and pedestrians? | **Computer Vision** |
| **৯** | Why is dataset diversity critical in Responsible AI development? | **To prevent and mitigate algorithmic bias.** |
| **১০** | Which factor is a core pillar of ethical AI governance? | **Data privacy and algorithmic transparency** |
